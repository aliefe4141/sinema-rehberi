Sinema Bilet ve Seans Rehberi
Bu proje BLM2537 Ağ Tabanlı Programlamaya Giriş dersi için geliştirilmektedir.

Nasıl Çalıştırılır?
1. Proje klasörünü bilgisayarınıza indirin veya klonlayın.

2. Klasörü VS Code ile açın.

3. VS Code eklentilerinden Live Server'ı kurun.

4. index.html dosyasına sağ tıklayıp "Open with Live Server" seçeneğine tıklayarak projeyi tarayıcıda çalıştırabilirsiniz.
